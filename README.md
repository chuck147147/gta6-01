# PALMERA BAY

An original top-down open-world crime game set in a sun-soaked coastal city. Explore five districts on foot, borrow a car, cruise past pastel villas and neon landmarks, or visit the beach and marina. This foundation includes a deterministic city, traffic, arcade driving, collisions, a minimap, and day and night screenshot scenes; police and missions arrive in later rounds.

- WASD / arrow keys: walk or drive
- Shift: sprint
- E / Enter: enter or exit a nearby unlocked car
- Space: handbrake
- Escape / P: pause; arrows and Enter select Resume or Restart
- Enter: start from the title screen

Run `node serve.ts`, then open http://localhost:8080. The static `game/index.html` also plays offline in desktop Chrome. Use `?seed=6` to choose the city seed and `?shot=title|foot|drive|night` to pose a scene.
